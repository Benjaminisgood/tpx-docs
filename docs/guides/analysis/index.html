实验处理与验收

  1. 准备原始 RGA CSV、温控日志及实验 TOML，保留源文件。
  2. 检查路径和采样信息，再拟合温程和对齐时间轴。
  3. 分别核对逐 AMU 真空、本底标定平台、碎片校正、逐物种响应归零与积分基线，不能互相替代。
  4. 按目标执行定量、归一化、面积或峰温分析，查看完整日志、曲线与来源。
  5. Calculate Ea 的 leading-edge 表观脱附能需人工选择窗口、单位和峰；拟合成功不代表方法适合所有实验。

保留全部采样点与重复温度，不静默抽稀或平均，不覆盖已有结果。详细原始格式与科学流程见 原有科学教程，其中的旧启动说明以本手册为准。

将上一次运行产物作为输入​

例如已完成一次真空扣除，下一阶段需要它的输出 CSV：

  1. 记下成功运行的运行 ID，在下一阶段的文件输入参数旁选择“选取运行产物”。
  2. 输入来源运行 ID，读取产物，选择对应输出文件；参数保存的是来源引用，准备时会解析成实际文件路径。
  3. 点击准备，核对冻结计划中的输入、输出和 input_bindings 来源记录，再明确确认运行。

来源必须是当前项目中已成功运行声明的产物。系统校验文件数量、路径和 SHA-256；原文件被修改或删除、引用其他项目，或同时填写显式路径与同名绑定时，准备或运行会拒绝。文件列表参数仍按命令要求的数量校验。目录输入和复杂重复参数继续显式填写并审阅。

绑定会保存在冻结计划和运行回执中，下一阶段开始前再检查一次，便于追溯结果使用了哪次运行、哪个文件。它不会自动执行下游步骤，也不把成功退出视为科学验收。
