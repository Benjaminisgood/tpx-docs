07

显式科研流程

研究者逐步选择输入、参数和新输出：校准支路处理 raw/full acquisition；脱附支路先完成 vacuum 与 fragmentation，随后才可选进入 response_zeroing、定量与曲线分析。

第一步
init → config inspect；需要特定实测通道时重复指定 --require-mass
中段门禁
raw: vacuum → fragmentation → calibration
aligned: vacuum → fragmentation → [response_zeroing apply] → quantify relative → composition → flow → rate
apply 没有 target，一次应用当前输入对应的全部匹配零点
四类基线
vacuum：fragmentation 前逐 AMU 真空电流；calibration background：只用于标气平台增量；response_zeroing：fragmentation 后从每样品/每物种的稳定无峰窗口扣常数；integration baseline：定量后定义面积参考线。不同样品不共享零偏或基线数值
分析边界
integration baseline preview → 人工审核 → accept；peaks/areas 从同一 normalized 表和 reviewed 定义复算。科学状态/摘要写入 experiment TOML，逐点证据默认进入 records/*.json，不生成基线、峰或积分 CSV
第一次使用 → 温程对齐 → 完整案例 → 处理中段 →
